## 1. 实现的具体功能

### 1.1 用户认证模块
| 功能 | 描述 |
|------|------|
| 发送验证码 | 手机验证码登录前的短信验证 |
| 手机号+验证码登录/注册 | 新用户自动注册，老用户直接登录 |
| 获取当前用户信息 | 获取登录用户的基本资料 |
| 刷新 Token | Token 过期前的续期机制 |
| 登出 | 清除登录状态 |

### 1.2 创作者档案模块
| 功能 | 描述 |
|------|------|
| 创建/更新创作者档案 | 设置身份类型、技能标签、工作经历等 |
| 获取我的档案 | 查询当前用户的完整档案信息 |
| 修改个人信息 | 更新昵称、头像、简介等基础信息 |

### 1.3 作品发布模块
| 功能 | 描述 |

| 文件上传 | 支持图片（jpg/png/webp）和视频（mp4/mov）上传 |

### 1.4 创作广场模块
| 功能 | 描述 |
|------|------|
| 获取广场作品流 | 按频道分页获取作品列表 |

### 1.7 供需对接模块

### 2.5 统一响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": { ... }
}
```

| 状态码 | 含义 |
|--------|------|
| 200 | 请求成功 |
| 400 | 参数校验失败 |
| 401 | 未登录或Token过期 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 409 | 数据冲突（如重复注册） |
| 500 | 服务器内部错误 |

### 2.6 认证方式

- 除登录/注册接口外，所有接口需携带 JWT Token
- 请求头格式：`Authorization: Bearer <token>`
- Token 有效期：7天
- 过期后前端引导用户重新登录

### 3.5 前端注意事项

1. **Token 管理**：登录成功后将 Token 存储在 localStorage，每次请求自动携带
2. **Token 过期处理**：收到 401 响应时，清除 Token 并跳转到登录页
3. **文件上传**：使用 `multipart/form-data` 格式，大文件考虑分片上传
4. **图片显示**：直接使用返回的 URL（如 `/uploads/works/xxx.jpg`）
5. **错误处理**：根据 `code` 字段判断业务状态，使用 `message` 字段提示用户
6. **分页处理**：根据 `total_pages` 判断是否还有更多数据
